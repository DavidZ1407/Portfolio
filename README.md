## Technologies

The portfolio website itself is built with the following technologies:

- **HTML5** — single-page semantic structure and inline SVG
- **CSS3** — custom properties, keyframe animations, and a unified responsive system
- **JavaScript (ES Modules)** — modular architecture with constants, modules, and shared utilities
- **WebGL / GLSL** — custom vertex and fragment shaders for the water-logo, subtitle cycle, portal vortex, modal, and ocean effects
- **Three.js (r128)** — hero shader parallax scene and GPU-based rendering
- **SVG** — inline water-distortion filters (`feTurbulence`, `feDisplacementMap`)
- **Boxicons** — icon set for navigation and contact links
- **Google Fonts** — Cinzel, Crimson Text, and UnifrakturMaguntia
- **GitHub Pages** — static hosting and automated deployment via GitHub Actions

> **Note:** Tools shown inside individual projects (e.g. Blender, Godot, Unreal Engine, C#, Krita, FMOD) are showcased as part of the work — they are not dependencies of the portfolio website itself.
